Tiempo actual con AEMET según tu ubicación

Esta demo usa la geolocalización del navegador para localizar tu posición, descarga las observaciones recientes de AEMET, busca la estación más cercana y muestra sus datos más recientes.

Introduce tu API Key y pulsa en “Usar mi ubicación”.
Notas:
• La geolocalización del navegador requiere HTTPS o localhost.
• AEMET devuelve primero una URL temporal en datos, y después hay que descargar ese JSON.
• Esta demo evita backend, así que tu API Key se usa en el navegador.

Aquí aparecerán la estación más cercana y las medidas meteorológicas disponibles.
